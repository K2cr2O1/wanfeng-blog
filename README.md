# wanfeng-blog

个人博客，基于 [Astro](https://astro.build) 与 [Fuwari](https://github.com/saicaca/fuwari) 模板构建。

## 技术栈

- 框架：Astro + Tailwind CSS
- UI：Svelte 组件 + TypeScript
- 包管理：pnpm
- 部署：Vercel

## 本地开发

```bash
pnpm install
pnpm dev
```

## 目录结构

- `src/content/posts/` — 博客文章（Markdown）
- `src/content/spec/` — 静态页面（关于、隐私、条款）
- `src/components/` — 组件
- `src/pages/` — 路由页面
- `public/` — 静态资源

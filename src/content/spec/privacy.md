# 隐私政策

最后更新日期：2026年8月1日

本博客是晚风小镇（www.wanfeng.cyou）的附属博客站点。我们非常重视您的个人信息保护。本隐私政策旨在向您说明：本博客在您访问和使用过程中可能收集哪些信息、如何使用与保护这些信息，以及您享有的相关权利与行使方式。

**与主站政策的关系。** 本政策是晚风小镇《隐私政策》（发布于主站 www.wanfeng.cyou）在博客站点的专项说明。主站《隐私政策》中关于运营主体、术语定义、同意方式、免责声明与联系方式的约定，同样适用于本博客；本政策与本博客实际运行情况不一致或未载明的事项，以本政策为准。

## 一、信息收集

**（一）自动收集的信息。** 当您访问本博客时，服务器及托管平台可能自动记录以下基础访问日志信息：

- IP 地址及通过 IP 可大致判断的地理位置（仅到城市/地区级别）
- 浏览器类型、版本、语言及操作系统信息
- 访问时间、访问页面路径、来源页面（Referer）及停留时长
- 访问异常记录（如高频请求、非法请求路径、安全扫描痕迹）

上述信息由服务器在请求发生时自动产生，**仅用于**保障网站稳定运行、排查页面故障、识别并抵御恶意攻击（如 DDoS、暴力破解、盗链）、进行必要的日志审计。此类信息**不会**被用于用户画像、行为分析或跨站追踪，也不会与任何账号体系、身份信息进行关联比对。

**（二）您主动提供的信息。** 本博客当前为纯静态展示站点，**不设置账号注册、留言、评论等收集您个人信息的功能**，您无需提供任何个人信息即可完整浏览全部内容。若未来上线评论等互动功能，我们会在功能上线前更新本政策，明确说明相应信息的收集范围与使用方式。

**（三）不收集的信息。** 本博客不收集您的真实姓名、身份证件号码、家庭住址、精确地理位置、通讯录、生物识别信息等敏感个人信息；不使用任何形式的用户行为追踪脚本、指纹识别技术（canvas fingerprinting 等）；不设置任何用于广告、统计或分析的第三方追踪脚本。

## 二、本地存储

本博客为提供主题与阅读偏好功能，使用浏览器 **localStorage** 存储以下偏好设置，**仅保存在您自己的设备上**：

- 主题模式（亮色 / 暗色）
- 自定义主题色（色相值）

上述存储内容不含任何可识别您身份的信息，不会上传至任何服务器，您可以随时通过浏览器设置清除。本博客不使用 Cookie、sessionStorage 或其他本地存储技术。您的浏览器可能根据自身策略缓存本博客的静态资源（图片、样式、脚本）以加速访问，这是浏览器默认行为。

## 三、第三方服务

本博客为正常提供内容与功能，会加载或跳转至以下第三方服务。您使用这些服务时，向相应服务商传输的数据由其独立处理，我们对其隐私保护措施不承担责任：

- **静态托管平台** — 本博客静态文件的托管与分发，平台方按其自身隐私与安全策略处理服务器访问日志
- **QQ 头像服务**（q.qlogo.cn）— 博客头像的加载。传输的数据：您的 IP 地址、浏览器环境
- **搜索服务** — 站内搜索使用 Pagefind 在本地完成索引与检索，**不产生任何外部数据传输**

本博客当前**不加载任何境外第三方资源**（如 Google Fonts 等），您的浏览器不会因访问本博客产生跨境的自动请求。若未来功能变化引入境外服务，我们将提前更新本政策。

## 四、未成年人保护

我们重视对未成年人的个人信息保护：

- 本博客为纯展示性站点，无需注册、不收集未成年人个人信息
- 博客公开内容面向公众，建议未成年人在监护人陪同下浏览
- 若未来上线互动功能，我们将对互动内容进行必要的审核与管理，并建议未成年人谨慎公开个人信息
- 若监护人发现未成年人未经同意提交了个人信息，可随时通过本政策第七条的邮箱/联系方式要求删除，我们将在核实后及时处理

## 五、信息保护与留存

**安全措施。** 本博客托管于第三方静态托管平台，依赖平台提供的基础安全防护（防火墙、访问控制、异常流量清洗、HTTPS 加密传输等）；主站与各子站之间相互隔离，权限独立管理。

**留存期限。** 服务器访问日志仅用于安全运维，保留期限以托管平台策略为准，通常不超过较短的运营周期。博客文章等公开内容长期保存，直至相应作者或我们主动删除。

**安全事件。** 若发生个人信息泄露、丢失或被篡改的安全事件，我们将尽力在合理时间内通过网站公告等方式向您告知事件基本情况、可能的影响以及已采取的处置措施。

**局限说明。** 互联网环境不存在绝对安全。我们将尽力保护您的信息，但无法保证数据传输与存储的绝对安全；任何通过互联网传输信息的行为都存在固有风险。

## 六、政策更新

我们可能根据法律法规要求、网站功能变化或管理需要，不时更新本隐私政策。更新后的政策将在本页面发布，并标注更新日期，自发布之时起生效。对于重大变更（如新增信息收集场景、新功能上线等），我们会在网站显著位置提示。您在政策更新后继续使用本博客，即视为接受更新后的政策。
